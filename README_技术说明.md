# 灵感画廊 · 技术说明（课程作业）
化名：张山 ｜ 学号后两位：17（占位，提交前请替换为你的 03–17）｜ 参考风格：Awwwards

## 1. 色彩
- 浅色基底色 #FAFAF8，近白不刺眼；正文墨色 #111114，形成高对比保证可读性。
- 强调色：电紫蓝 #5B5BF7 与青绿 #00E0B0，用于评分条渐变、链接下划线与 hover 反馈。
- 提供“深色模式”切换（右上角 🌙/☀️），用 CSS 变量整体换肤，降低长时间浏览疲劳（学习点：情感化交互与可控性反馈）。

## 2. 字体
- 标题：Arial Black + 黑体系无衬线（font-family 变量 --title），字号 clamp() 自适应，粗重字重建立视觉锚点。
- 正文：系统字体栈（--body），行高 1.7、字距微调，保证长时间阅读舒适。
- 说明：未引用外部字体文件，离线也能完整呈现，方便打包与课堂演示。

## 3. 框架布局
- 固定悬浮导航，滚动超过 40px 自动收缩（高度 72→54px），节省视口并保持可达。
- 内容区采用 CSS columns 实现卡片瀑布流；卡片 “break-inside:avoid” 防止断裂。
- 卡片信息层级：封面 → 标题 → 元信息标签（奖项/类别/技术/年份/均分）→ 四维评分条，浏览瞬间即可判断质量。
- 筛选条 sticky 吸顶，支持“奖项 × 类别 × 技术栈”多维交叉筛选，过滤后卡片带错峰淡入重排。
- 详情页为左右分栏（主视觉 + 信息面板），面板 sticky；整站响应式（860/560 断点）。

## 4. 人机交互
- 卡片 hover：封面渐显遮罩与“查看案例 →”，评分条展开，位移 +1px 微动效。
- 导航链接下划线生长；按钮 hover 变色上移；主题切换即时生效并持久化到 localStorage。
- 三次点击动线：首页卡片 → 详情页 → 留言板。
- 留言板（预留）：昵称/内容必填校验、200 字实时统计、提交后列表顶部插入并动画弹出；当前用 localStorage 保存，代码注释标出 POST /api/messages 接入点。
- 移动端：汉堡按钮占位抽屉导航（预留）。
